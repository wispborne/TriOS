- [x] Update the 21 `overrideWith` uses in `test/` if the 3.x signatures changed. **No signature changes; nothing needed updating.**
- [x] Re-test one of the tests that works around the `.future` hang by listening and polling. Try a plain `await ... .future` and record whether 3.x fixed it. **3.x did not fix it — it made it worse and explained it. In 3.x a provider with no active listener gets `onCancel`, and for stream-backed providers `onCancel` pauses the underlying `StreamSubscription` (`element.dart:186` in the pub cache). `container.read(p.future)` starts the provider but leaves zero listeners, so the stream is paused before it emits and the await never returns. This broke 24 tests across four files that used to pass. `AsyncNotifier` is unaffected — a `Future` cannot be paused. The listen-and-poll workaround was right for the wrong reason: what makes it work is the listener, not the polling. New `awaitFirstValue()` helper holds a listener open and completes on the first value; the four files now use it and run instantly instead of timing out.**
